## Component Anatomy
### Card
- Background: `color/surface/card/default`
- Border radius: `size/radius/card`
- Padding: `size/spacing/card/inner`
- Shadow: `shadow/card/resting`

## Interaction States
- Hover: opacity shift using `opacity/hover` token
- Focus: 2px ring using `color/border/focus`
- Disabled: `opacity/disabled` applied to container

## Layout Rules
- Sidebar width: 240px (fixed, dark navy)
- Content max-width: 1280px
- Section title color: `color/label/section/default`

## Typography Scale
- Display: Noto Sans TC 24/32, weight 700
- Body: Roboto 14/20, weight 400
- Label: Inter 12/16, weight 500
